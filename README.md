Vehicle Classification System
This is a Flask web application that uses a deep learning Convolutional Neural Network (CNN) built with TensorFlow to classify images of vehicles.

Dataset Source
The training dataset is hosted on Kaggle. You can access and download it here:
(https://www.kaggle.com/datasets/mohamedmaher5/vehicle-classification)

Supported Types
The model classifies images into 7 categories:

Auto Rickshaws

Bikes

Cars

Motorcycles

Planes

Ships

Trains
